# umask Implementation — Task Tracker

> **Rule**: After EVERY step, run `make kernel.bin` AND `make -C tests test-umask` AND `make -C tests test-boot test-shell test-stat test-chmod test-mkdir test-mknod` (or the full `make -C tests test`) to verify nothing is broken.

---

## [x] Step 0: vsprintf `%o` (and `%u`/`%x`) support

**vsprintf only handled `%c`, `%s`, `%d`. Added octal + unsigned + hex.**

| File | Change |
|------|--------|
| `libc/stdio/vsprintf.c` | Add `%o` (octal), `%u` (unsigned), `%x` (lowercase hex). Fixed overflow bug in `%d` digit-counting loop. |

**Test**: `printf("%o %u %x", 022, 42, 255)` → `22 42 ff`

## [x] Step 1: `umask` syscall — field + handler + libc + command + test

**No behavioral change to file creation.** Pure add of the umask concept.

| File | Change |
|------|--------|
| `kernel/task.h` | Add `uint16_t umask;` to `struct task` |
| `kernel/task.c` | `t->umask = 022` in `task_alloc()`; `child->umask = parent->umask` in `task_fork()` |
| `kernel/syscall.h` | `#define SYS_umask 60` |
| `kernel/syscall.c` | Implement `sys_umask(int mask)`; register `SYS_umask` in `syscall_init()` |
| `libc/unistd/umask.c` | **New** — `int umask(int mask)` via `int $0x80` with eax=60 |
| `libc/include/unistd.h` | Declare `int umask(int);` |
| `libc/Makefile` | Add `umask.o` to UNISTD_OBJS |
| `shell/bin/umask.c` | **New** — `umask` command: no-arg prints current, arg sets it |
| `shell/bin/Makefile.mk` | Add `shell/bin/umask` to `BIN_CMDS` |
| `tests/build-disk.sh` | Add `umask` to the `for cmd` loop |
| `tests/Makefile` | Add `shell/bin/umask` to both `BIN_CMDS` lists; add `test-umask` recipe |
| `tests/test-umask.sh` | **New** — test `umask` prints `022`, set to `077`, read back `077` |

**Test**: `umask` → `022`; `umask 077` → `umask` → `077`; then restore `umask 022`.

## [x] Step 2: `open()` mode propagation — kernel VFS + ext2 + libc + shell callers

**Files created via O_CREAT now respect umask.**

**Architectural note**: `umask` MUST be a built-in shell command (like `cd`) because it
modifies the shell process's own umask. A `fork+exec` binary cannot affect the parent.
Added built-in handler to `shell_elf.c` alongside the `/bin/umask` binary.

| File | Change |
|------|--------|
| `kernel/syscall.c` `sys_open` | Add `int mode` param; apply `mode = mode & ~current->umask` when O_CREAT |
| `kernel/vfs.h` | `vfs_create_file(const char *path, uint16_t mode)` |
| `kernel/vfs.c` | Set `inode->i_mode = S_IFREG \| (mode & S_IPERM)` before `add_entry` |
| `kernel/ext2.c` `ext2_add_entry` | Use `entry->i_mode` instead of hardcoded `0x81A4` for new regular files |
| `libc/unistd/open.c` | Make variadic: when `flags & O_CREAT`, extract mode from stack (`*(&flags + 1)`) and pass via `"d"` to `int $0x80` |
| `libc/include/unistd.h` | Change to `int open(const char *, int, ...);` |
| `shell/bin/dd.c` | Add `0644` mode to open with O_CREAT |
| `shell/bin/cp.c` | Same |
| `shell/bin/touch.c` | Same |
| `shell/bin/write.c` | Same |
| `shell/shell_elf.c` | Add `0644` mode to open with O_CREAT; add built-in `umask` handler |
| `tests/test-umask.sh` | **Extend** — add open/create test: set umask 027, `touch /x`, `stat /x`, verify mode `33184` (0100640 octal) |

**Test**: With umask 027, `touch /x; stat /x` shows `mode=33184` (== 0100640 = S_IFREG \| 0640).

## [x] Step 3: `mkdir` + `mknod` mode propagation

**`mkdir` and `mknod` now also respect umask.**

| File | Change |
|------|--------|
| `kernel/syscall.c` `sys_mkdir` | Add `int mode` param; apply `mode = mode & ~current->umask` |
| `kernel/vfs.h` | `vfs_mkdir(const char *path, uint16_t mode)`; add `uint16_t mode` to `vfs_inode_ops.mkdir` |
| `kernel/vfs.c` | Pass mode: `parent->ops->mkdir(parent, name, mode)` |
| `kernel/ext2.c` `ext2_mkdir` | Add `uint16_t mode` param; use `EXT2_S_IFDIR \| (mode & S_IPERM)` |
| `kernel/syscall.c` `sys_mknod` | Apply `mode = mode & ~current->umask` |
| `tests/test-umask.sh` | **Extend** — add mkdir test (umask 077, `mkdir /tmp/d`, verify `040700`) and mknod test |

**Test**: With umask 077, `umask 077 mkdir /d; stat /d` shows `16832` (== 040700 = S_IFDIR|0700). With umask 027, `umask 027 mknod /n c 1 3; stat /n` shows `8608` (== 020640 = S_IFCHR|0640).
