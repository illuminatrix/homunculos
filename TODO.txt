TODO: Toybox Porting

Toybox (https://github.com/landley/toybox) is the target userspace.
The kernel needs new syscalls and VFS features to run it.

Build (on Linux host, not in-kernel):
  CROSS_COMPILE=i686-elf- make defconfig toybox
  Build statically against musl; our ELF loader handles the result.

===== P0: Blocking (most commands fail without these) =====

[x] brk/sbrk   -- per-task heap via syscall.     kernel/syscall.c
    Need a writable region in the page directory, task-local break addr.

[x] stat/fstat/lstat   -- SYS_stat (106), SYS_fstat (108), SYS_lstat (107)
    Define struct stat (i386), expose inode metadata (size, type, mtime)
    through VFS inode ops.  syscall.c

[x] getdents (i386 SYS_getdents=141)   -- SYS_getdents64 (220)
    Directory read returns space-separated names via read(fd); toybox
    expects struct linux_dirent64.  Need a real getdents syscall that
    iterates vfs_inode_ops->readdir.  kernel/syscall.c + vfs

[x] ioctl    -- SYS_ioctl (54)
    At minimum TCGETS/TCSETS for terminal control (echo, line buffering,
    signal chars).  VGA text driver and PS/2 kbd driver need ioctl
    handlers.

[x] chdir/getcwd   -- SYS_chdir (12), SYS_getcwd (183)
    Add cwd buffer to task struct, resolve relative paths using
    cwd prepend + normalize_path helper in syscall.c.  kernel/syscall.c + vfs

[x] getpid/getppid   -- SYS_getpid (20), SYS_getppid (64)
    Trivial: read from scheduler_get_current()->pid / parent_pid.

[x] lseek   -- SYS_lseek (19)
    VFS file struct already tracks f_pos.  Add syscall to set it.

[x] uname   -- SYS_uname (122)
    Return fixed struct utsname (i686, illuminatrix, ...).

===== P1: Pipeline / Shell (for a usable shell) =====

[x] pipe    -- SYS_pipe (42)

[x] dup2   -- SYS_dup2 (63)

[x] waitpid options   -- pid==-1 (any), pid==child_pid, WNOHANG
