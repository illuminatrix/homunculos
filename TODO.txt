TODO: Toybox Porting

Toybox (https://github.com/landley/toybox) is the target userspace.
The kernel needs new syscalls and VFS features to run it.

Build (on Linux host, not in-kernel):
  CROSS_COMPILE=i686-elf- make defconfig toybox
  Build statically against musl; our ELF loader handles the result.
